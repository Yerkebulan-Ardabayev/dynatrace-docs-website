# Visualizations and tiles

* Overview
* 1-min read
* Published Dec 13, 2021

[Dashboards Classic](/managed/analyze-explore-automate/dashboards-classic "Learn how to create, manage, and use Dynatrace Dashboards Classic.")

Dynatrace offers a number of specialized tiles that you can add to your dashboards, as well as various data visualizations you can configure in [Data Explorer](/managed/analyze-explore-automate/explorer "Explore Data Explorer topics, from creating and editing metric queries to learning advanced query syntax and resolving common issues.") and then pin to your dashboards as tiles.

## Visualizations

You can create data visualizations in [Data Explorer](/managed/analyze-explore-automate/explorer "Explore Data Explorer topics, from creating and editing metric queries to learning advanced query syntax and resolving common issues.") and then pin them to your dashboards as tiles. If you're new to creating visualizations, see [Get started with Data Explorer](/managed/analyze-explore-automate/explorer/explorer-quick-start "Use Data Explorer to create your first query, select a visualization, inspect the results, and pin the finished visualization to a dashboard.") for a quick walkthrough.
