# Configure custom metric metadata

# Configure custom metric metadata

* How-to guide
* 1-min read
* Updated on Oct 01, 2026

To configure metadata for a custom metric in the UI, follow the steps below.

## Step 1 Open the custom metric

Settings 2.0 metadata applies only to custom or schemaless metrics, not built-in or code-registered metrics. You can create metadata before ingesting the first data point.

1. Go to **Metrics** and find the custom metric. For details on the available filters, see [Metric filters and sorting](/managed/analyze-explore-automate/metrics-browser/metrics-browser-filters-and-fields#filter "Look up Metrics browser filters, sorting options, metric details, and custom metadata fields before creating charts or editing custom metrics.").
2. Select  in the **Details** column to display the metric's details.

## Step 2 Edit the metadata

1. Select **Edit metadata**. This button appears in the expanded row only for custom metrics.
2. On the **Metric metadata** page, edit the fields you need. For descriptions of the available fields, see [Metadata for custom metrics](/managed/analyze-explore-automate/metrics-browser/metrics-browser-filters-and-fields#metadata "Look up Metrics browser filters, sorting options, metric details, and custom metadata fields before creating charts or editing custom metrics.").

   If the page displays a lock, you don't have write permission to edit the selected metric's metadata.

## Step 3 Save the metadata

1. Select **Save changes**. The updated metadata becomes part of the metric descriptor and is available in the **Metrics** browser and Data Explorer.
