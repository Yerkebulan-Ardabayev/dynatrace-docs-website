# Data Explorer

# Data Explorer

* 1-min read
* Updated on Oct 05, 2026

Use Data Explorer to build metric queries and work with their results. Start with the tutorial, then use the query reference and the visualization settings reference to build and display queries. Then use the advanced mode guide and the results guide to refine, analyze, share, export, and troubleshoot results. To pin results to a dashboard, see the Dashboards section.
