# Geographic regions - IP address mapping rules API

* Справочник
* Обновлено 21 июля 2026

Устарело

Этот API устарел. Используйте [схему Map IP addresses to locations](/managed/dynatrace-api/environment-api/settings/schemas/builtin-rum-ip-mappings "Просмотр таблицы схемы настроек builtin:rum.ip-mappings среды мониторинга через Dynatrace API.") вместо него.

**Geographic regions - IP address mapping rules** API позволяет управлять конфигурацией сопоставления IP-адресов с географическими местоположениями. Управлять той же конфигурацией можно через интерфейс Dynatrace в разделе **Settings > Web and mobile monitoring > Map IP addresses to locations**.

[### Просмотр конфигурации

Получить обзор сопоставлений IP-адресов.](/managed/dynatrace-api/configuration-api/rum/geographic-regions-ip-address/get-configuration "Прочитать конфигурацию сопоставления IP-адресов через Dynatrace API.")[### Обновление конфигурации

Обновить конфигурацию сопоставлений IP-адресов.](/managed/dynatrace-api/configuration-api/rum/geographic-regions-ip-address/put-configuration "Обновить конфигурацию сопоставления IP-адресов через Dynatrace API.")
