# Установка

* 1 минута чтения
* Обновлено 09 июл. 2026

Dynatrace предлагает два типа ActiveGate: Environment ActiveGate и Cluster ActiveGate. Развёртывания Dynatrace Managed, как правило, требуют обоих типов, хотя наиболее важный тип, [Cluster ActiveGate](/managed/managed-cluster/installation/install-cluster-activegate "Install a Cluster ActiveGate on Linux or Windows to route OneAgent traffic or run Synthetic monitors, and connect it to your Managed Cluster."). Для развёртываний Dynatrace Managed см. [дополнительные варианты использования ActiveGate для Dynatrace Managed](/managed/managed-cluster/basics/managed-deployments#scenario-2-pure-dynatrace-managed-setup "Understand how Dynatrace Managed deployments evolve from a basic internal setup to a globally distributed high-availability architecture.").

Environment ActiveGate можно установить:

* с помощью установщика на виртуальном или физическом хосте. Такой вариант называется **развёртыванием на основе хоста**
* в контейнере. Такой вариант называется **контейнеризованным развёртыванием**
