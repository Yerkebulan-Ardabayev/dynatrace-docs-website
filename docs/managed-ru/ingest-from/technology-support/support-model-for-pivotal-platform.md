# Модель поддержки Dynatrace для Broadcom Elastic Application Runtime

* 5 минут чтения
* Обновлено 23 июля 2026 г.

Broadcom поддерживает выпуски N, N-1 и N-2 Elastic Application Runtime (EAR). Подробности, смотри в [политике поддержки Broadcom﻿](https://support.broadcom.com/group/ecx/productlifecycle).

Dynatrace придерживается той же [модели поддержки﻿](https://d1fto35gcfffzn.cloudfront.net/support/PivotalLifecycleMatrix.pdf), что и Broadcom, обеспечивая единый цикл обновлений. Однако поддержка OneAgent и [Dynatrace Service Broker](/managed/ingest-from/setup-on-container-platforms/cloud-foundry/install-the-service-broker-for-cloud-foundry-dashboard-tile "Установка и настройка Dynatrace Service Broker для VMware Tanzu Platform dashboard tile.") для Elastic Application Runtime может отставать от выпусков Broadcom, чтобы обеспечить достаточное время на тестирование.

Подробности в [объявлениях о прекращении поддержки](/managed/whats-new/technology/end-of-support-news "Объявления о прекращении поддержки для технологий, поддерживаемых Dynatrace.") для OneAgent.

Существует два варианта [Dynatrace OneAgent BOSH Release﻿](https://github.com/Dynatrace/bosh-oneagent-release). Полный BOSH OneAgent release не содержит инсталлятора OneAgent. Вместо этого инсталлятор загружается из среды Dynatrace во время развёртывания release. Рекомендуется использовать последний release Dynatrace OneAgent BOSH add-on, поскольку в нём содержатся последние улучшения. При этом выше указаны минимально необходимые версии BOSH Release для каждой версии VMware Tanzu application service.

1

Все перечисленные выше версии были проверены с несколькими версиями OneAgent.

2

До мая 2020 г. (до версии 1.191) Dynatrace предоставлял трёхмесячный льготный период для обновления дистрибутивов Cloud Foundry из-за разницы в сроках поставки. С мая 2020 г. Dynatrace ускорил цикл тестирования, поэтому модель поддержки больше не требует трёхмесячного льготного периода. Для всех выпусков OneAgent до мая 2020 г. (ранее версии OneAgent 1.191) Dynatrace продлевает поддержку на три месяца, чтобы выполнить обязательства перед существующими установками OneAgent согласно прежней модели поддержки.

3

Существует две схемы нумерации версий. Неизменяемый OneAgent BOSH release версионируется так же, как и OneAgent. Неизменяемый OneAgent BOSH release является рекомендуемым методом развёртывания OneAgent. Предыдущие версии использовали облегчённый подход, доступный на GitHub, и применяли схему нумерации версий GitHub.
